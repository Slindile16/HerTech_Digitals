# HerTech_Digital

The promotional website for HerTech_Digital, Slindile Mthimunye’s web development business. The site introduces the business, explains its services and process, showcases live projects, and provides clickable contact and social links.

## View the website

This is a static website and does not require a build step or package installation. On Windows, open it from the project folder in PowerShell:

```powershell
Start-Process .\index.html
```

## Site sections

- **Home:** Business introduction and primary contact call to action.
- **Services:** Website design and development, landing pages and refreshes, and ongoing support. Pricing is described as flexible and negotiable.
- **Selected work:** [Slindile’s personal portfolio](https://slindile16.github.io/Personal-Portfolio/) and [Mathembies Kitchen](https://slindile16.github.io/Mathembies_Kitchen/).
- **About:** Slindile’s introduction, studies, skills, and approach to working with clients.
- **Contact:** Clickable email, phone, WhatsApp, LinkedIn, and GitHub links.

## Project files

- `index.html` — page content and metadata.
- `styles.css` — layout, navy and pink branding, and responsive styles.
- `script.js` — mobile navigation and current-year footer.
- `logo-crop.png` — cropped logo artwork used in the header and footer.
- `logo.jpeg` — original supplied logo image.
